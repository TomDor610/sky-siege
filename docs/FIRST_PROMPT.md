# ההודעה הראשונה ל-Claude Code

העתק והדבק את הטקסט הבא כהודעה הראשונה, אחרי שפתחת את Claude Code בתיקייה של הפרויקט:

---

קרא את CLAUDE.md ואת docs/ROADMAP.md. אנחנו מתחילים את שלב 1 במפת הדרכים: מעבר לפרויקט מסודר.

1. אתחל Git ובצע commit ראשון של המצב הנוכחי כמו שהוא.
2. הקם פרויקט Vite (JavaScript, בלי framework) ופרק את index.html למודולים הגיוניים תחת src/: נתונים וקבועים, התקדמות ושמירה, פיזיקה, טירות והגנות, בוט, ציור, ממשק בנייה, HUD וזרימה.
3. **בלי לשנות משחקיות, איזון, מראה או מפתחות שמירה.** התוצאה צריכה להתנהג בדיוק כמו המקור.
4. הוסף בדיקות Playwright: טייס אוטומטי דרך window.__sky שמריץ דו-קרב וקמפיין בשלוש רמות הקושי ובודק שאין שגיאות ושהקרב מסתיים. הוסף גם צילומי מסך בתצוגת טלפון לרוחב ולאורך.
5. הגדר `npm run build` כך שייצר קובץ dist/index.html יחיד ועצמאי (למשל עם vite-plugin-singlefile).
6. כשתסיים, הראה לי סיכום קצר של המבנה, תריץ את הבדיקות, ותגיד לי איך להריץ את המשחק מקומית.

לפני שאתה מתחיל, הצג תוכנית קצרה ותחכה לאישור שלי.
